- 每个仓库需要一个agent to agent 目录，存放架构沟通的文档和规范；这个文档主要由架构维护 Agent 编写和维护，其他 agent 在本文档中回复；
- 每个仓库需要分不同的agent进行开发，编制如下：
    1 个架构维护 Agent + 1 个框架建构 Agent + n 个专项开发 Agent + 1 个验证文档 Agent
- 具体需要几个专项开发由框架 Agent 决定
- 专项开发的职责与权限：1. 维护固定的目录文件，agent 与 agent 之间的职责目录不允许重叠，所有agent 的目录总和能覆盖整个仓库的开发代码部分
- 框架维护和框架建构 agent 涉及整体框架，可能有例外；
- 架构维护不允许写参与具体的代码维护，框架建构 agent 可以负责具体的框架维护，但不涉及具体的功能实现；
