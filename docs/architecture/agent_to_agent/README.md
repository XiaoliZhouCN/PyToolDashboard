# Agent To Agent Directory

## 1. 目录定位

本目录用于存放仓库内 Agent 与 Agent 之间的架构沟通文档和协作记录。

该目录主要服务于：

- 架构维护 Agent
- 框架建构 Agent
- 专项开发 Agent
- 验证文档 Agent

## 2. 典型内容

推荐放置以下类型文件：

- Agent 职责说明
- 目录归属表
- 交接说明
- 架构回复记录
- 验证反馈与回执

## 3. 维护原则

- 本目录由架构维护 Agent 主维护
- 其他 Agent 可在约定文件中追加回复
- 已稳定的仓库级规则，应上收至：
  - `docs/conventions/`
  - `docs/architecture/`

## 4. 边界

本目录不是：

- 临时代码草稿目录
- 业务实现目录
- 长期替代正式规范的地方

若某项规则已经被验证为长期有效，应尽快整理进正式规范文件。
