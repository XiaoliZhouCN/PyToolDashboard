# Mermaid Editor Features And Usage

## 1. 文档定位

这份文档面向 **工具使用者**，用于说明：

- 当前已经具备哪些功能
- 每个功能怎么操作
- 目前有哪些已知限制

它不是开发设计文档。
如果你后续想标记“需要增加哪些功能”或“哪些体验需要优化”，建议直接在这份文档对应章节上补充说明。

## 2. 当前可以做什么

目前 `mermaid_editor` 已经支持以下能力：

### 2.1 打开 Markdown 并读取 Mermaid 图

- 打开本地 Markdown 文件 √
- 自动提取其中的 Mermaid 代码块 √
  - [x] 已修复 `tools\mermaid_editor\samples\workflow.md` 中子图 ID 被边引用时误生成顶层节点的问题；当前会优先复用已定义的节点或子图，只在完全未定义时才新建节点。

* 如果一个 Markdown 里有多个 Mermaid 图，可以在图列表里切换 √

### 2.2 可视化查看图结构

- 在右侧画布中查看节点、边、子图 √
- [x] 默认布局已调整为平铺式初始布局，顶层节点和子图默认不重叠；新建节点/子图也会按当前父层级顺序排布。
- 同时保留左侧 Mermaid 源码视图 √
- 在“源码视图”和“图形视图”之间来回工作 √

### 2.3 手工调整布局

- 拖拽节点位置 √
- 拖拽子图位置 √
- 拖拽子图时，会带着其内部内容一起移动 √
- 布局信息会保存到 sidecar 文件，而不是直接写进 Mermaid 语法 √
- [x] 已增加子图右键菜单中的“适配大小”选项，可按当前内容自动收缩到包围盒大小。
- [x] 已增加预览视图级别的缩放，工具栏不再跟随一起缩放。
- [x] 已支持拖动画布空白区域进行整体平移。

### 2.4 编辑图结构

- 新增节点 √
- 新增子图 √
- [x] 新增节点/子图按钮已改为统一双输入框窗口，一次输入 ID 和显示文本 / 标题。
- [x] 已支持双击空白画布新增节点，双击子图在子图内新增节点。
- [x] 节点右键菜单已增加“重命名节点 ID”和“提升为子图”，重命名改为属性面板内编辑，不再弹窗。
- [x] 新增节点、子图现在会按当前层级平铺放置，默认不重叠。
- 新增边 √
- [x] 新增边已改为画布交互模式：点击 `Add Edge` 或右击节点/子图选择“新增边”，从起点拖出一条跟随鼠标的线，点击目标节点/子图后创建默认实线箭头细边。

- 重命名节点 ID √
- 修改节点显示文本 √
- 重命名子图 ID √
- 修改子图标题 √
- [x] 节点和子图的 ID / 显示文本修改已改为右侧属性面板双字段编辑，不再连续弹出多个窗口。
- 修改边的起点、终点、标签、样式
- [x] 已支持双击选中边并在属性面板直接修改标签；右键菜单可切换实线、虚线、加粗、无箭头样式。箭头方向等更细粒度样式仍待补充。
- 删除节点 √
- 删除子图 √
- 删除边 √
- [x] 删除功能已支持 `Backspace` 和 `Delete` 快捷键，不再只依赖按钮。

## 3. 界面区域说明

主窗口大致分成左右两部分。

### 3.1 左侧区域

左侧工作区目前分为上下两部分。

#### 上半部分

上半部分大致占左侧区域的 `1/3`，并继续分为左右两列。

##### 左列

1. 当前文件路径
2. Mermaid 图列表
3. `Apply Source` / `Save File` 按钮

##### 右列

1. 当前选中对象摘要
2. 节点 / 子图 / 边的详情编辑面板
3. 节点 / 子图的连线点侧向偏好设置

#### 下半部分

下半部分大致占左侧区域的 `2/3`，用于显示当前选中图的 Mermaid 源码编辑区。

### 3.2 右侧区域

右侧是图形画布，顶部有一排画布操作按钮：

- `Add Node`
- `Add Edge`
- `Add Subgraph`
- `Rename`
- `Delete`
- `Fit Selected`
- `- / 100% / +`
- `Save Layout`

右侧还包含：

- 右键菜单
- 画布缩放比例显示
- 多选框选交互
- 工具栏底部拖拽调高条

## 4. 常用操作

### 4.1 打开文件

操作方式：

1. 启动工具
2. 点击顶部工具栏 `Open Markdown`
3. 选择 `.md` 或 `.markdown` 文件

结果：

- 左侧会显示该文件中的 Mermaid 图列表
- 右侧会显示当前选中的图

### 4.2 切换不同的 Mermaid 图

操作方式：

1. 打开一个包含多个 Mermaid 代码块的 Markdown
2. 在左侧图列表中点击不同条目

结果：

- 左侧源码编辑区会切换到对应 Mermaid 源码
- 右侧画布会切换到对应图

### 4.3 拖拽节点布局

操作方式：

1. 在右侧画布里点击节点
2. 拖动到新位置
3. 松开鼠标

结果：

- 节点位置会更新
- 布局数据会同步保存到当前图状态

### 4.4 拖拽子图布局

操作方式：

1. 点击子图边框
2. 拖动到新位置

结果：

- 子图会移动
- 子图内部的节点和嵌套子图会一起移动

### 4.5 新增节点

操作方式：

1. 如果希望节点进入某个子图，先选中该子图
2. 点击 `Add Node`
3. 在弹出的统一输入窗口中输入节点 ID 和显示文本

结果：

- 新节点会出现在画布中
- 如果当前选中了子图，新节点会默认挂到该子图下

### 4.6 新增子图

操作方式：

1. 如果希望在某个子图内部新增子图，先选中父子图
2. 点击 `Add Subgraph`
3. 在弹出的统一输入窗口中输入子图 ID 和子图标题

结果：

- 新子图会加入当前图结构

### 4.7 新增边

操作方式：

1. 点击 `Add Edge`
2. 点击起点节点或子图
3. 观察跟随鼠标移动的临时连线
4. 点击目标节点或子图

结果：

- 新边会加入当前图结构
- 默认创建为实线箭头细边（`-->`）
- 左侧 Mermaid 源码会同步回写这条边
- 连线默认落在元素边框交点，而不是元素中心

### 4.8 重命名节点、子图或边

操作方式：

1. 在画布中选中节点、子图或边
2. 在左侧工作区右列的详情面板中直接修改字段
3. 点击 `Apply`

也可以：

- 点击 `Rename` 后聚焦到主字段
- 双击节点后直接聚焦节点属性
- 双击边后直接聚焦边标签属性
- 右击节点或子图后，从菜单进入对应操作

结果：

- ID 和显示文本 / 标题会更新
- 如果节点 ID 变化，相关边会同步更新到新的节点 ID
- 边支持修改起点、终点、标签和样式

### 4.9 连线点侧向偏好

操作方式：

1. 选中节点或子图
2. 在详情面板中找到 `Anchor Side`
3. 选择 `auto / top / right / bottom / left`
4. 点击 `Apply`

结果：

- 当前对象的边连接点会优先使用指定侧向
- 若为 `auto`，则自动使用与目标方向对应的边框交点

### 4.10 删除节点、子图或边

操作方式：

1. 在画布中选中目标
2. 点击 `Delete`

结果：

- 删除节点时，会一并删除连接到该节点的边
- 删除子图时，会一并删除其内部的子图、节点以及相关边
- 删除边时，只移除当前选中的边
- 也支持直接按 `Backspace` 或 `Delete`

### 4.11 多选、框选与对齐

操作方式：

1. 按住 `Ctrl` 点击节点或子图，可进行多选
2. 按住 `Ctrl` 在画布空白区拖动，可框选节点和子图
3. 多选后按：
   - `Ctrl+Q`：纵向居中对齐
   - `Ctrl+W`：横向居中对齐
   - `Ctrl+T`：对子图执行适配大小

结果：

- 可同时选择多个节点和子图
- 边不参与多选
- 选中对象会按快捷键要求进行对齐
- 当拖动多选中的任一节点或子图时，其他被选中对象会一起移动

### 4.12 直接修改 Mermaid 源码

操作方式：

1. 在左侧源码编辑区修改 Mermaid 文本
2. 点击 `Apply Source`

结果：

- 工具会重新解析源码
- 如果语法可被当前解析器支持，右侧画布会刷新

注意：

- 如果源码为空，会提示不能应用
- 如果源码解析失败，会弹出错误提示

### 4.13 保存文件

操作方式：

1. 点击顶部工具栏 `Save`
2. 或点击左侧 `Save File`

结果：

- 当前 Markdown 文件会被回写
- 当前布局 sidecar 文件也会一起保存

### 4.14 缩放与平移画布

操作方式：

1. 在预览视图中滚动鼠标滚轮进行缩放
2. 或点击工具栏 `- / 100% / +`
3. 在画布空白区域按住鼠标左键拖动，可整体平移视图
4. 按 `Ctrl+H`，可将视图移回有效内容中心并恢复到 `50%`

结果：

- 缩放和平移只作用于预览视图
- 工具栏不会一起缩放
- 缩放围绕画布中心进行，而不是围绕鼠标位置

### 4.15 子图适配大小

操作方式：

1. 选中子图
2. 点击工具栏 `Fit Selected`
3. 或右击子图，选择 `适配大小`
4. 或直接按 `Ctrl+T`

结果：

- 子图会自动收缩或扩展到包围当前内容的大小

### 4.16 调整顶部工具栏高度

操作方式：

1. 将鼠标移动到画布顶部工具栏下边界
2. 按住分隔条向下或向上拖动

结果：

- 工具栏高度会随拖动变化
- 当按钮较多时，可展开为多行显示，避免顶部按钮被裁切

## 5. 保存机制说明

当前会保存两类数据。

### 5.1 Markdown 原文

图结构相关的 Mermaid 文本，保存在原始 Markdown 文件中。

### 5.2 布局 sidecar

手工布局保存在与 Markdown 同目录的 sidecar 文件中，例如：

- `workflow.md`
- `workflow.md.layout.json`

这样做的好处是：

- Mermaid 源码仍然可读
- 手工布局不会因为重新解析 Mermaid 而丢失

## 6. 命令行导出功能

除了桌面窗口操作，目前还支持命令行导出。

### 6.1 导出 SVG

```powershell
python run.py action --project-root . --action-name export_svg --markdown-file samples/sample_workflow.md
```

### 6.2 导出 PNG

```powershell
python run.py action --project-root . --action-name export_png --markdown-file samples/sample_workflow.md
```

### 6.3 使用 launcher 导出

```powershell
..\..\launchers\tool_mermaid_editor.bat . action --action-name export_svg --markdown-file samples/sample_workflow.md
..\..\launchers\tool_mermaid_editor.bat . action --action-name export_png --markdown-file samples/sample_workflow.md
```

默认情况下，导出结果会写到当前 `project_root` 下的：

- `artifacts/mermaid_editor/`

## 7. 当前已知限制

目前已经能完成基础编辑和导出，但仍有这些限制：

- 解析器主要覆盖 `flowchart` 子集
- 边已支持拖拽式创建和基础样式切换，但箭头方向等更细粒度编辑还未完成
- 已提供基础 `Ctrl+Z` 撤销，但还没有重做
- 历史管理仍是当前版本的一版基础实现，还没有形成完整的自动历史快照与恢复策略
- PNG / SVG 导出属于当前图模型导出，不是浏览器画布的逐像素截图
- 更复杂的 Mermaid 语法和嵌套场景还需要继续完善

## 8. 如何继续反馈

这份文档面向使用者，因此后续你不需要关心内部由哪个模块、哪个 Agent 负责。

如果你在使用过程中发现问题，或者希望增加某项能力，直接用自然语言告诉我即可，例如：

- “这里的拖拽体验不合理”
- “我希望新增一种边的箭头样式”
- “保存后再次打开，布局没有恢复”
- “源码和图形视图的同步时机不对”

为了让我更快理解问题，建议反馈时尽量带上以下信息：

1. 你在做什么操作
2. 现在实际发生了什么
3. 你期望它应该怎样表现
4. 如果方便，补充对应章节或截图

例如：

- “在 `4.4 拖拽子图布局` 这个场景里，拖动嵌套子图时会误选父子图；我希望只拖动当前命中的子图。”
- “在 `4.14 缩放与平移画布` 这里，触控板缩放太灵敏；我希望缩放速度更平滑。”

收到反馈后，我会在内部完成这些工作：

1. 判断这是体验问题、结构问题、保存问题还是解析问题
2. 分析需要调整哪些模块
3. 决定交给哪个专项 Agent 处理
4. 在需要时拆成多个协同子任务

你只需要继续从“用户视角”描述问题和期望，不需要自己判断模块归属。
